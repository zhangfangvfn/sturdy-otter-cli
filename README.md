# sturdy-otter-cli

Haskell · TypeScript · Deno

给自己省点事的小工具

## 用法

```bash
cat data.txt | python main.py
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/sturdy-otter-cli.git
cd sturdy-otter-cli
pip install -r requirements.txt
```

## 备注

就是给自己省点事，没做太多抽象。
